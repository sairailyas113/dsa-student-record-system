## Project Description
This project is a **Library Management System** developed as part of the
**Data Structures and Algorithms (DSA)** course.

The system efficiently manages library records such as books and their issue
status. It supports adding, editing, deleting, searching, issuing, and returning
books through a frontend user interface.

The project demonstrates practical implementation of core DSA concepts without
using any external database.

## Features
- Add, edit, and delete books
- Search books by ISBN and title
- Issue and return books
- Manage book issue requests using a queue (FIFO)
- Display books in sorted order using insertion sort
- Data persistence using JSON file storage

## Data Structures Used
- List (to store book objects)
- Dictionary (hash map) for fast ISBN-based lookup
- Queue (FIFO) for managing issue requests
- Insertion Sort for sorted book display

## Technologies Used
- Python
- Data Structures and Algorithms
- Frontend User Interface
- Google Colab
